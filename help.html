Read Aloud+ help

Open Word’s Home tab → Read Aloud+. Select text, or place your cursor inside the sentence to read, then press Play.

Use Pause / Resume, Stop, sentence buttons and the speed slider. Offline voices are listed first. Add Windows voices in Settings → Time & language → Speech → Add voices.

In Word, hold Ctrl+Alt+Shift: P plays or pauses, X stops, Right / Left moves one sentence, and Up / Down changes speed. Open the pane once each Word session. With no selection, Play starts at the beginning of the sentence containing the cursor.

If a voice fails, another voice is tried. If reading pauses with an error, choose another voice and Resume, or skip with Next sentence.

Installation: close Word yourself, then run install.cmd beside the built manifest.xml. Reopen Word and look for Read Aloud+ on Home or under My Add-ins → Developer Add-ins. To remove it, close Word and run uninstall.cmd.

The first visit needs internet access. Cached files help with brief outages, but Office startup and online voices can still need the network. Ask Koral for help if Word blocks installation or reading.
