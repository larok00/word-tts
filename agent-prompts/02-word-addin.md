  - `src/lib/player.js`: a reading-session controller (state machine: idle → playing ↔ paused → stopped/finished). Takes chunks + a "speech engine" object (dependency-injected; the real one wraps `window.speechSynthesis`, tests use a fake). Features: play from chunk i, pause, resume, stop, next/previous sentence, change rate live (restart the current chunk at the new rate), callbacks `onChunkStart(i)`, `onStateChange(state)`, `onError(msg)`.
    - **Voice fallback**: if an utterance errors (error other than "interrupted"/"canceled"), retry the same chunk with the next voice in a fallback list (prefer `localService === true` voices, same language first); after all voices fail, report the error and stay paused at that chunk instead of crashing.     - **Chromium watchdogs**: speak one chunk per utterance (chunks are already ≤ max chars); include a watchdog: if no `onend`/`onerror` arrives within a generous timeout based on chunk length and rate (e.g. 4 s + 150 ms per char / rate), treat it as an error → retry/fallback.
