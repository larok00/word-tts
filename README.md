# word-tts

A reliable text-to-speech reader for Microsoft Word (Windows desktop), built as a
dependable replacement or backup for Word's Read Aloud.

**Status:** planning. No app code yet. See [NOTES.md](NOTES.md) for goals, open
questions, architecture options and the decision log.

## Layout
- `bend/`: Bend 2 experiments (text splitting / chunking). `bend bend/hello.bend`

## Tooling
- Bend 2.0.39 (`~/.bend/bin/bend`), Codex CLI 0.166.0
