Keyboard shortcuts

In this pane: Space plays or pauses; Esc stops; ← / → changes sentence; + / − changes speed. Form controls keep their usual keys.

In Word: Ctrl+Alt+Shift+P plays or pauses; S stops; Right / Left changes sentence; Up / Down changes speed (with the same three modifiers). Open the pane once to activate.

Offline voices work without a speech service. The first visit needs a network connection to load this add-in and Office.
